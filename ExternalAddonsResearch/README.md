# External Addons Research

This directory is dedicated to researching, prototyping, and testing external open-source addons, tools, libraries, and integration patterns for the Investment Process OS (IPOS).

## Purpose
- **Exploratory Coding:** Write scratch scripts and prototype integrations (e.g., testing new data APIs, indicators, or packages like `pandas-ta`).
- **Research Logs:** Document findings on third-party libraries and toolkits.
- **VCS Separation:** Keep experimental code and configurations isolated from the production packages (`ipos/`), CLI commands, and test suites.
