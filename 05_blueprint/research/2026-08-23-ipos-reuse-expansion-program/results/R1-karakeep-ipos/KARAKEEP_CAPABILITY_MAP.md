# Karakeep Capability Map

**Verified version context:** docs v0.33.0; latest tagged release observed `v0.33.2` on 2026-08-23. Tagged source/OpenAPI checks use `v0.33.2` unless stated otherwise.

| Capability | Current verified behavior | IPOS classification | Reason / constraint |
|---|---|---|---|

| Self-host/local | Official Docker Compose; persistent `/data` and Meilisearch volume | `ADOPT_AS_OPTIONAL` | Local-first fit, but adds always-on services. [Compose](https://github.com/karakeep-app/karakeep/blob/v0.33.2/docker/docker-compose.yml) `[VERIFIED_PRIMARY]` |

| Notes | Text bookmarks plus per-bookmark note field | `ADOPT` | Human context can remain attached to source. [OpenAPI](https://github.com/karakeep-app/karakeep/blob/v0.33.2/packages/open-api/karakeep-openapi-spec.json) `[VERIFIED_PRIMARY]` |
| Highlights | Searchable highlights; API/CLI list/get endpoints | `ADOPT_AS_OPTIONAL` | Valuable candidate-claim input, never an operational rule by itself. [OpenAPI](https://github.com/karakeep-app/karakeep/blob/v0.33.2/packages/open-api/karakeep-openapi-spec.json) `[VERIFIED_PRIMARY]` |
| Tags | Manual/AI tags; API records `attachedBy` as `human` or `ai` | `ADOPT` | Initial integration accepts only human-attached control tags; AI tags are descriptive metadata. ## Ownership conclusion

| Responsibility | Owner |
|---|---|
| Live working research inbox and human curation | Karakeep |
| Preserved captured page/file assets | Karakeep, mirrored by versioned dump/export |
| Append-only evidence events consumed by IPOS | New thin read-only adapter output |
| Candidate interpretation/claims | Downstream evidence governance, not R1 |
| Operational Playbook/config rules | Existing repository review/versioning |
| Numerical source truth, scores and aggregates | Existing IPOS/DuckDB |
| Weekly report and optional narration | Existing IPOS |
